## About the Project

This portfolio is designed to present my technical journey, projects, achievements, and professional interests in a clean, modern, and interactive interface.

As a Computer Science and Engineering student, I am interested in Data Science, Artificial Intelligence, data analytics, and building practical software solutions.

The portfolio provides a central place to explore my work, review my certificates, learn about my technical skills, and connect with me regarding professional opportunities.

## Features

- **Personal Introduction:** An overview of my background, interests, and career goals.
- **About Me:** My approach to data, technology, and problem-solving.
- **Education:** Academic background and educational milestones.
- **Certificates & Achievements:** Technical certifications, hackathon recognition, and other accomplishments.
- **Featured Projects:** Selected projects across AI, data analytics, and software development.
- **Technical Skills:** An overview of programming languages, frameworks, databases, and development tools.
- **Experience:** Project experience and relevant activities.
- **Resume:** Access to my professional resume.
- **Contact Section:** A way to connect with me regarding opportunities and collaborations.
- **Responsive Design:** A layout designed for desktop and mobile screens.
- **Interactive UI:** Navigation, visual effects, and animated design elements.

## Featured Projects

### 1. EduPredict

**Category:** Artificial Intelligence / Machine Learning

An AI-powered personalized education system designed to analyze student performance and provide personalized learning recommendations.

**Technologies:** Python, TensorFlow, Keras, Streamlit, MongoDB.

### 2. CAMOSPHERE

**Category:** Web Development / Interactive Experiences

A virtual campus tour platform concept that helps visitors explore campus spaces through an interactive digital experience.

**Technologies:** React, React Three Fiber, Expo GL, Blender.

### 3. CodeAtlas

**Category:** AI / Developer Tools

An AI-powered developer intelligence platform designed to analyze code repositories, help users understand software architecture, and generate documentation.

**Technologies:** React, Vite, Node.js, Express.js, MongoDB, IBM Bob.

### 4. Securitisation Risk Dashboard

**Category:** Data Analytics / Business Intelligence

A Power BI dashboard focused on securitised loan portfolio analysis, credit-risk monitoring, delinquency patterns, and portfolio loss insights.

**Technologies:** Power BI, DAX, Data Analytics, Risk Analysis.
