# Integrated React Portfolio

A single React + Vite portfolio bringing the requested sections into one responsive website. The visual theme uses Abhijeet's dark/cyan/violet/neon palette as requested for the Abhijeet background reference, with the hero/about renamed to Shrihari Kulkarni per the conversation.

## Sections in the requested order
1. Hero / Landing
2. About
3. Education
4. Certificates
5. Projects
6. Skills
7. Resume
8. Achievements & Experience
9. Contact

## Run locally
Requirements: Node.js 20+ recommended.

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Before publishing
- Replace sample academic details, certificates, project details and experience entries with verified personal information.
- Replace placeholder GitHub, LinkedIn and email URLs.
- Add your own resume as `public/assets/resume.pdf`. The provided sample resume from the Shalini reference is deliberately not linked as your resume.
- Certificate images are copied from the provided Shalini reference archive as temporary visual placeholders. Replace them with your own verified certificates.
- Project links currently point to generic GitHub URLs; replace each with its actual repository/demo.
